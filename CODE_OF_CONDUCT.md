# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we are committed to a welcoming, harassment-free experience for
everyone who takes part in this project, regardless of background or identity.
We expect all participants - in issues, pull requests, and any other project
space - to be respectful and constructive.

## Reporting

If you experience or witness unacceptable behaviour, please report it
privately to the maintainers at **info@3dbyggeri.dk**. Reports are handled
confidentially, and the maintainers will respond as promptly as they can.
